FortiGate에서 제공하는 Virtual IP(VIP)으로 웹 서비스를 제공할 때, 다음과 같은 몇 가지 확인해야 할 점들이 있습니다.

1.  **VIP 구성 확인** : 우선, VIP이 올바르게 구성되어 있는지 확인합니다. VIP의 IP 주소, 포트 번호, 프로토콜 및 서버가 올바른지 확인합니다. 또한, VIP의 상태를 확인하여 활성화되어 있는지 확인합니다.
2.  **네트워크 경로 확인** : 네트워크 경로를 확인하여 웹 서버가 VIP으로 통신하는 경로가 올바르게 구성되어 있는지 확인합니다. 이는 방화벽 정책, 라우팅 테이블, 및 스위칭 기기의 설정에 대한 확인을 포함합니다.
3.  **포워딩 정책 확인** : 포워딩 정책이 올바르게 구성되어 있는지 확인합니다. 포워딩 정책이 활성화되어 있으면서, 웹 서버의 VIP으로 통신하는 패킷이 올바르게 포워딩되는지 확인합니다.
4.  **트래픽 필터링 확인** : 트래픽 필터링 규칙이 올바르게 구성되어 있는지 확인합니다. 트래픽 필터링 규칙이 활성화되어 있으면서, 웹 서버의 VIP으로 통신하는 트래픽이 필터링되지 않는지 확인합니다.
5.  **트레이스루트 확인** : 웹 서버가 VIP으로 통신하는 트레이스 루트를 확인하여 통신 경로가 올바르게 구성되어 있는지 확인합니다.
6.  **웹서버 구성 확인** : 웹 서버의 구성과 설정을 확인하여 웹 서버가 올바르게 작동하는지 확인합니다. 특정 포트나 서비스가 차단된 경우가 있는지 확인합니다.

위의 사항을 확인한 후에도 문제가 해결되지 않을 경우, FortiGate의 로그를 확인하여 문제의 원인을 찾을 수 있습니다. 로그를 통해 웹 서버가 VIP으로 통신하는 트래픽이 포워딩되는지, 트래픽 필터링이 적용되는지 확인할 수 있습니다.
