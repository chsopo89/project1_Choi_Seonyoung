FortiGate의 Virtual IP(VIP)로 제공하는 웹 서비스가 중단된 문제를 해결하기 위해 다음과 같은 점검 순서를 따르세요.  

1. **VIP 프로토콜 및 포트 설정 확인**  
   - VIP가 HTTP(80) 또는 HTTPS(443)로 구성되었는지 확인하세요. 웹 서비스가 HTTPS를 사용한다면, VIP의 프로토콜이 HTTPS로 설정되어 있어야 합니다.  
   - VIP의 포트가 웹 서비스가 실제로 사용하는 포트와 일치하는지 확인하세요. 예: 웹 서버가 8080 포트에서 실행 중이라면 VIP도 8080 포트를 사용해야 합니다.  

2. **애플리케이션 제어 및 웹 필터링 프로필 점검**  
   - VIP 정책에 할당된 애플리케이션 제어(Application Control) 프로필이 HTTP/HTTPS 트래픽을 차단하고 있지 않은지 확인하세요.  
   - 웹 필터링(Web Filter) 프로필이 웹 서비스의 요청을 차단하지 않는지 확인하세요. 예: 특정 URL 패턴이나 MIME 타입이 필터링 대상이 될 수 있습니다.  

3. **시스템 로그 및 오류 메시지 확인**  
   - FortiGate의 시스템 로그에서 VIP 관련 오류, 연결 타임아웃, 또는 트래픽 드롭 메시지를 확인하세요. 예: `diag debug flow show` 명령어로 트래픽 흐름을 추적할 수 있습니다.  

4. **헬스 체크 설정 검토**  
   - VIP의 헬스 체크 설정이 올바르게 구성되었는지 확인하세요. 예: 헬스 체크가 서버의 특정 포트(예: 80)를 점검하지만, 웹 서비스가 443 포트에서 실행 중이라면 헬스 체크가 실패할 수 있습니다.  

5. **웹 서버 구성 및 리스닝 인터페이스 확인**  
   - 웹 서버가 VIP의 IP 주소를 사용하여 리스닝하고 있는지 확인하세요. 예: 웹 서버가 `127.0.0.1`만 리스닝하고 있다면, FortiGate의 VIP IP로 들어오는 트래픽을 처리하지 않습니다.  
   - 서버의 포트 바인딩 설정이 올바르게 구성되어 있는지 확인하세요.  

6. **네트워크 장비 및 라우팅 확인**  
   - FortiGate와 웹 서버 간의 라우팅 경로가 정상인지 확인하세요. 예: `diagnose sys top` 명령어로 네트워크 상태를 점검할 수 있습니다.  
   - 서버의 방화벽 설정이 VIP의 IP 주소를 허용하고 있는지 확인하세요.  

7. **최근 변경 사항 확인**  
   - VIP 설정, 정책, 또는 서버 구성에 최근 변경 사항이 있는지 확인하세요. 예: 정책의 방향성(인바운드/아웃바운드)이 잘못 설정되었거나, IP 주소가 변경된 경우입니다.  

8. **트래픽 캡처 및 분석**  
   - `tcpdump` 또는 `diag debug flow show` 명령어로 트래픽을 캡처하여 VIP로 들어오는 요청이 정상적으로 전달되고 있는지 확인하세요.  

**추가 고려 사항**:  
- SSL/TLS 설정이 필요한 경우, FortiGate의 SSL 인스펙션 설정이 웹 서비스의 암호화 방식과 호환되는지 확인하세요.  
- 웹 서비스가 특정 프록시나 로드 밸런서를 사용하는 경우, 해당 구성이 VIP와 정상적으로 통합되어 있는지 점검하세요.  

위 점검 항목을 순차적으로 확인하여 문제 원인을 파악하세요. 확실하지 않은 설정이나 명령어는 추측하지 않고, 실제 구성 정보를 기반으로 분석해야 합니다.
