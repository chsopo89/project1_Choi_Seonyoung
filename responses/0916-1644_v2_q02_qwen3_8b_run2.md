FortiGate의 Virtual IP(VIP)로 제공하던 웹 서비스가 갑자기 중단된 상황에서, VIP 설정과 정책은 정상이며, 서버 자체에는 문제가 없고, 방화벽과 웹서버 간의 통신도 정상이라면, 문제는 웹 서비스 자체의 구성이나 특정 네트워크 설정, 포트 전달(Port Forwarding) 설정, 상태 기반 필터링(Stateful Inspection), 또는 방화벽의 보안 정책에서 특정 트래픽을 차단하는 설정일 수 있습니다.

**확인해야 할 항목 및 점검 순서:**

1. **VIP 설정 및 상태 확인:**  
   - VIP 설정이 정상인지 확인합니다. 특히, VIP에 할당된 IP 주소, 대상 서버 IP, 포트 번호, 프로토콜 등이 정확한지 확인해야 합니다.  
   - VIP가 활성 상태인지 확인합니다. FortiGate의 CLI에서 `diagnose sys virtual-ip` 명령을 사용해 상태를 확인할 수 있습니다.

2. **포트 전달 설정 확인:**  
   - 웹 서비스에 필요한 포트(예: 80, 443)가 포트 전달 설정에 포함되어 있는지 확인합니다.  
   - 포트 전달 설정이 활성 상태인지 확인합니다. CLI에서 `get firewall policy` 명령으로 확인할 수 있습니다.

3. **웹 서비스 포트 사용 여부 확인:**  
   - 웹 서버에서 실제로 웹 서비스가 포트 80 또는 443을 사용하는지 확인합니다. 예를 들어, `netstat -an | grep :80` 또는 `ss -tuln` 명령을 통해 확인할 수 있습니다.

4. **방화벽의 상태 기반 필터링 검사:**  
   - 방화벽에서 상태 기반 필터링이 비활성화되어 있는지 확인합니다. 상태 기반 필터링이 비활성화되면 특정 트래픽이 차단될 수 있습니다.  
   - CLI에서 `get system settings` 명령으로 상태 기반 필터링 설정을 확인합니다.

5. **웹 서버의 방화벽 설정 확인:**  
   - 웹 서버 자체에서 방화벽 설정이 웹 서비스 트래픽을 차단하고 있지 않은지 확인합니다. 예를 들어, `iptables` 또는 `firewalld` 등의 설정을 점검해야 합니다.

6. **트래픽 로그 및 경고 메시지 확인:**  
   - 방화벽에서 트래픽 로그를 확인해 웹 서비스 트래픽이 차단되었는지 확인합니다. CLI에서 `diagnose firewall log` 명령을 사용하면 해당 트래픽이 어떤 이유로 막혔는지 확인할 수 있습니다.

7. **서버의 서비스 재시작 또는 로그 확인:**  
   - 웹 서비스가 정상적으로 실행되고 있는지 확인합니다. 서버의 웹 서버 로그를 확인해 서비스가 중단되었는지, 오류 메시지가 있는지 확인합니다.

8. **DNS 설정 및 네임 리졸루션 확인:**  
   - 사용자가 웹 서비스에 접근할 때 DNS 주소가 올바르게 설정되어 있는지 확인합니다. `nslookup` 또는 `dig` 명령으로 확인할 수 있습니다.

위 점검 순서에 따라 문제 원인을 추적하면, 웹 서비스 중단의 정확한 원인을 파악할 수 있습니다. 특히, 방화벽의 상태 기반 필터링, 포트 전달 설정, 서버 내부 웹 서비스의 실행 상태 등이 주요 요소입니다.
