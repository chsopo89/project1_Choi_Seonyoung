FortiGate의 Virtual IP(VIP)로 제공하던 웹 서비스가 갑자기 중단된 경우를 분석해 보겠습니다.

**확인할 항목**

1. **VIP 설정**: VIP가 올바르게 구성되었는지 확인합니다. VIP의 IP 주소, 포트 번호, 프로토콜(예: TCP, UDP, SCTP), 가중치 및 순위가 올바르게 구성되었는지 확인합니다.
2. **포워딩 설정**: 포워딩 규칙이 올바르게 구성되었는지 확인합니다. 포워딩 규칙이 VIP IP 주소로 가는 트래픽을 올바르게 포워딩하고 있는지 확인합니다.
3. **로드 밸런서**: 로드 밸런서가 올바르게 구성되었는지 확인합니다. 로드 밸런서가 VIP IP 주소로 도착하는 트래픽을 올바르게 분배하고 있는지 확인합니다.
4. **웹 서버**: 웹 서버가 올바르게 작동하는지 확인합니다. 웹 서버의 서비스 상태를 확인하고, 웹 서버가 올바르게 작동하는지 확인합니다.
5. **방화벽 정책**: 방화벽 정책이 올바르게 구성되었는지 확인합니다. 방화벽 정책이 웹 서버로 가는 트래픽을 올바르게 허용하고 있는지 확인합니다.
6. **네트워크 통신**: 웹 서버와 FortiGate 사이의 네트워크 통신이 올바르게 발생하는지 확인합니다. 웹 서버가 방화벽에 접속하고, 방화벽이 웹 서버로 가는 트래픽을 올바르게 허용하는지 확인합니다.
7. **디버그 로그**: 디버그 로그를 확인하여, VIP IP 주소로 도착하는 트래픽이 올바르게 처리되는지 확인합니다.

**점검 순서**

1. **VIP 설정과 포워딩 설정 확인**
 VIP 설정과 포워딩 설정이 올바르게 구성되었는지 확인합니다.
2. **로드 밸런서 확인**
 로드 밸런서가 올바르게 구성되었는지 확인합니다.
3. **웹 서버 상태 확인**
 웹 서버의 서비스 상태를 확인합니다.
4. **방화벽 정책 확인**
 방화벽 정책이 올바르게 구성되었는지 확인합니다.
5. **네트워크 통신 확인**
 네트워크 통신이 올바르게 발생하는지 확인합니다.
6. **디버그 로그 확인**
 디버그 로그를 확인하여, VIP IP 주소로 도착하는 트래픽이 올바르게 처리되는지 확인합니다.

**추가 조치**

* 디버그 로그를 확인하고, 문제의 원인을 파악하십시오.
* 만약 문제가 VIP 설정이나 포워딩 설정과 관련이 있다면, VIP 설정이나 포워딩 설정을 변경하십시오.
* 만약 문제가 로드 밸런서와 관련이 있다면, 로드 밸런서를 재기동하십시오.
* 만약 문제가 방화벽 정책과 관련이 있다면, 방화벽 정책을 변경하십시오.
