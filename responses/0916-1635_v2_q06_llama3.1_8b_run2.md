네트워크 장비에서 시간을 정확하게 유지하는 것은 중요합니다. Cisco 스위치에서 시간이 틀어진 경우를 확인하려면 다음의 순서로 확인해 보세요.

**1. 스위치의 현재 시간을 확인합니다.**
스위치에 접속하여 `show clock` 명령어를 실행하여 현재 시간을 확인합니다.

**2. NTP 설정을 확인합니다.**
스위치에 NTP 설정이 제대로 되어 있는지 확인합니다. `show running-config` 명령어를 실행하여 NTP 설정이 있는지 확인합니다.

**3. NTP 서버의 상태를 확인합니다.**
스위치에서 NTP 서버의 상태를 확인합니다. `show ntp status` 명령어를 실행하여 NTP 서버가 정상적으로 작동하는지 확인합니다.

**4. NTP 서버의 시간을 확인합니다.**
스위치가 틀어진 시간을 갖고 있는지 확인하기 위해, NTP 서버의 시간을 확인합니다. 이때, NTP 서버의 시간이 스위치의 시간보다 1초 빠르게 또는 느리게 틀렸는지 확인합니다.

**5. 스위치에서 시간을 리셋합니다.**
위의 확인 과정을 통해 스위치에서 시간을 리셋해 보세요. `clock reset` 명령어를 실행하여 스위치의 시간을 리셋합니다.

이때, NTP 서버를 변경하는 것이 필요하다면 다음과 같이 조치합니다.

*   **NTP 서버를 확인합니다.** 스위치에서 사용하는 NTP 서버가 정상적으로 작동하는지 확인합니다. 
*   **NTP 서버를 변경합니다.** NTP 서버가 정상적으로 작동하지 않는다면, NTP 서버를 변경하고, 스위치에서 새로운 NTP 서버를 설정합니다.

**점검 결론.**

*   스위치에서 시간이 틀어진 경우를 확인하기 위해서는 위의 순서대로 확인하고, 스위치에서 시간을 리셋합니다.
*   NTP 서버를 변경하는 것이 필요하다면, 스위치에서 사용하는 NTP 서버를 확인하고, 새로운 NTP 서버를 설정합니다.
