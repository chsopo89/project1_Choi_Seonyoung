FortiGate에서 Virtual IP(VIP)로 제공하는 웹 서비스가 갑자기 중단된 경우, 다음과 같은 항목을 확인하고 점검하는 순서를 권장합니다.

1. **Virtual IP 설정 확인**:  
   - VIP의 상태가 정상인지 확인하세요. `diagnose firewall vip list` 명령어를 통해 VIP의 상태를 확인합니다.  
   - VIP의 IP 주소, 서버 그룹, VIP 번역 상태 등을 확인해야 합니다. VIP의 상태가 중단된 상태나 오류 상태가 아닌지 점검해야 합니다.

2. **정책 설정 확인**:  
   - VIP가 사용하는 정책이 정상적으로 구성되어 있는지 확인하세요. `diagnose firewall policy list` 명령어를 통해 정책 상태를 확인합니다.  
   - 정책의 상태가 활성화된 상태인지, 그리고 트래픽이 해당 정책을 통해 전달되는지 확인해야 합니다.  
   - 정책에서 사용된 포트 번호가 올바르게 설정되어 있는지, 웹 서비스가 사용하는 포트(예: 80, 443)가 정상적으로 열려 있는지 확인해야 합니다.

3. **인터페이스 및 상태 확인**:  
   - VIP가 사용하는 인터페이스의 상태가 정상인지 확인하세요. `diagnose interface list` 명령어를 사용합니다.  
   - 인터페이스의 상태가 DOWN 상태이거나, 설정 오류가 있는지 확인해야 합니다.

4. **DNS 설정 확인**:  
   - VIP의 FQDN이 정확하게 설정되어 있는지 확인하세요. `diagnose firewall vip get <VIP_NAME>` 명령어를 사용하여 VIP의 설정을 확인합니다.  
   - DNS 서버 설정이 올바르게 구성되어 있으며, 외부에서 VIP에 접근할 수 있는지 확인해야 합니다.

5. **서버 및 웹 서비스 상태 확인**:  
   - 서버에 접근 가능한지 확인하고, 웹 서비스가 실행 중인지 점검합니다. `system diagnostic` 또는 `system info` 명령어를 사용하여 서버 상태를 확인할 수 있습니다.  
   - 웹 서비스가 정상적으로 작동하는지 확인하되, 외부에서 액세스할 수 없는 원인을 찾는 것이 중요합니다.

6. **포트 포워딩 및 NAT 설정 확인**:  
   - VIP 설정에서 포트 포워딩 또는 NAT 설정이 필요한 경우, 해당 설정이 정확하게 구성되어 있는지 확인하세요.  
   - 웹 서비스가 사용하는 포트가 방화벽에서 제대로 전달되는지 확인해야 합니다.

7. **로그 및 디버깅 정보 확인**:  
   - `diagnose firewall log list` 명령어를 사용하여 로그를 확인하고, 웹 트래픽이 방화벽에서 정상적으로 통과하고 있는지 확인합니다.  
   - 로그에서 특정 트래픽이 막히는 패턴이 있는지 점검하세요.

8. **FortiGate 시스템 상태 및 리소스 확인**:  
   - 시스템 메모리, CPU 사용률, 네트워크 인터페이스 상태 등 시스템 리소스가 과부하 상태인지 확인하세요.  
   - `diagnose sys top` 명령어를 통해 시스템의 실시간 상태를 확인할 수 있습니다.

위 점검 순서를 따라 문제 원인을 찾으시기 바랍니다. 정확한 설정 내용이나 상태를 확인할 수 없으면 추가적인 점검이 필요할 수 있습니다.
