네트워크 장비를 이전하는 동안 발생하는 문제를 해결하기 위한 순서와 확인 항목을 다음과 같이 설명합니다.

1.  **네트워크 장비의 VLAN 설정 확인**

    네트워크 장비의 VLAN ID, VLAN 이름, VLAN 속성을 동일하게 맞춘 후 VLAN의 트래픽이 적절하게 분리되고 있는지 확인합니다. VLAN ID, 이름, 속성을 확인하기 위해 다음 명령어를 사용합니다.

    ```
    show vlan
    show vlan statistics
    ```
2.  **스위치 포트 설정 확인**

    전환된 포트에 대해 STP, STP Edge Port, VLAN Trunking Port를 확인합니다. STP Edge Port는 스위치와 연결된 단말이 스위치 내 VLAN에 포함되지 않도록 설정합니다.

    ```
    show spanning-tree
    show spanning-tree vlan <VLAN_ID>
    ```
3.  **LLDP와 네이밍**

    장비의 LLDP 설정과 VLAN 이름을 일치시켜 VLAN ID와 포트의 네이밍이 동일한지 확인합니다.

    ```
    show lldp neighbor
    show lldp neighbors
    ```
4.  **스위치의 로드 бал런스**

    스위치의 로드밸런싱 설정이 동일한지 확인합니다. 로드밸런싱을 사용하지 않도록 확인합니다.

    ```
    show hardware
    show redundancy
    ```
5.  **STP**

    STP 상태를 확인합니다. 스위치는 STP을 활성화할 수 있습니다. 활성화되어 있다면 STP를 비활성화하는 것을 검토합니다.

    ```
    show spanning-tree
    ```
6.  **스위치의 배포 순서**

    스위치 배포 시, 스토리지 및 네트워크 하드웨어의 배포 순서를 지키고, 스위치 간 네트워크 배포 순서도 동일하게 해야 합니다.

    ```
    show inventory
    ```
