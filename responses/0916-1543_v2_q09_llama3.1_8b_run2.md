Cisco 스위치에 광 SFP 모듈을 연결했으나 인식되지 않는다면, 여러 가지 이유가 있을 수 있습니다. 다음과 같은 순서로 상태를 확인해 보겠습니다.

**1. 모듈의 상태 확인**
 
 모듈이 작동하고 있는지 확인하려면 `show module` 명령어를 사용합니다.

```
show module
```

이 명령어로 스위치의 모듈 상태를 확인할 수 있습니다. 

**2. 모듈의 포트 상태 확인**

이어서 모듈에 연결된 포트 상태를 확인합니다.

```
show interface <port-number>
```

해당 포트가 UP인지 DOWN인지 확인하고, 케이블이 잘 연결되어 있는지 확인합니다.

**3. 모듈의 버전 확인**

모듈의 버전을 확인하여 Cisco 공식 홈페이지에서 해당 버전의 드라이버를 다운받아 보는 것이 좋습니다.

```
show module detail
```

**4. 시스템 로그 확인**

모듈이 인식되지 않는다면, 시스템 로그를 확인하여 에러 메시지를 찾습니다.

```
show logging
```

로그 메시지를 살펴본 후, 모듈을 교체하거나, 드라이버를 업그레이드하는 과정을 거치게 됩니다.

**5. 모듈 교체**

다음과 같은 경우라면, 모듈을 교체하는게 좋습니다.

* 모듈이 손상된 경우
* Cisco 공식 홈페이지에서 제공하는 드라이버를 다운로드하고, 설치 후에도 문제가 있는 경우

모듈 교체 후, `show module` 명령어로 모듈 상태를 다시 확인합니다.

**A/S 방법**

* **보증 받은 모듈**

Cisco 공식 홈페이지에서 구매한 모듈은 보증을 받을 수 있습니다. 공식 홈페이지에서 보증 요청을 넣어 주시면 됩니다.

* **보증을 받지 않은 모듈**

보증을 받지 않은 모듈의 경우, 해당 문제가 시스템 문제인 경우 보증을 받을 수 있습니다. 하지만, 보증을 받지 않은 모듈의 경우, 스위치 제조사 공식 홈페이지에서 제공하는 지원 서비스를 이용해야 합니다.

**서드파티 모듈의 A/S 방법**

서드파티 모듈을 사용할 경우, 해당 회사에서 제공하는 A/S 방법에 따라 진행해야 합니다. 이 경우, 공식 홈페이지에 문의를 보내서 A/S 방법을 확인해 보는 것이 좋습니다.

**서드파티 모듈의 문제점**

서드파티 모듈의 문제점으로는, 다음이 있습니다.

* 보증이 받지 못하는 경우
* 지원이 제대로 되지 않는 경우
* 시스템 성능 문제가 발생하는 경우

**결론**

Cisco 스위치에 광 SFP 모듈을 연결했으나 인식되지 않는다면, 확인 순서에 따라 진행하여 문제를 해결하도록 합니다. A/S는 보증 받은 모듈의 경우 보증을 받을 수 있으며, 서드파티 모듈의 경우 해당 회사에서 제공하는 A/S 방법에 따라 진행합니다. 서드파티 모듈의 문제점을 파악하고, 해당 문제가 발생하는 경우, 공식 홈페이지에 문의를 하는 것이 좋습니다.
