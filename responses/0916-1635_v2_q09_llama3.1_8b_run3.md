Cisco 스위치에서 광 SFP 모듈이 인식되지 않는다면, 먼저 모듈의 상태를 확인하고자 할 것입니다.

**장비 상태 확인**

```bash
show interface transceiver
```

또는

```bash
show interface transceiver [interface-id]
```

이 명령어는 장비가 SFP 모듈을 인식하고 있는지, 그리고 모듈의 상태를 알려줍니다. (단, 일부 장비의 경우 show transceiver detail, show interface detail 로도 확인이 가능합니다.)

**일부 예외**

* 장비의 버전이 낮은 경우 장비가 모듈을 인식하지 못할 수 있습니다.
* 모듈이 제조사의 정품이 아니면 장비가 모듈을 인식하지 못할 수 있습니다.

장비와 모듈이 호환되지 않는 경우, Cisco 에서 지원해 드립니다.

**적절한 절차**

1. 장비의 버전을 확인하고 최신 버전으로 업그레이드하세요.
2. 모듈의 제조사 및 모델을 확인하고, 모듈이 Cisco 공식 웹사이트에서 지원하는 모델인지 확인합니다.
3. Cisco 공식 홈페이지에서 지원되는 제품을 확인하고, 관련하여 정품을 교체하시기를 바랍니다.
4. 문제가 여전히 발생하는 경우, Cisco의 기술 지원팀으로 문의하여 문제를 해결하세요.
