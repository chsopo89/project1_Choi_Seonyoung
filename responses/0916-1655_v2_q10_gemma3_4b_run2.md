## Cisco 스위치에서 Juniper 스위치로 전환 시 문제 해결 및 작업 순서

현재 상황은 Cisco 스위치에서 Juniper 스위치로 전환 중이며, 802.1Q 트렁크 및 동일 VLAN ID 설정으로 인해 기본적인 링크 연결과 LLDP 인식은 정상적으로 이루어지고 있음에도 불구하고 일부 VLAN만 통신이 안되고, 간헐적인 루프성 트래픽이 발생하고 있다는 점입니다. 단말 간 내부 통신은 정상임을 확인하신 점이 중요합니다. 이 문제를 해결하기 위해 다음과 같은 단계별 검증 및 작업 순서를 제안합니다.

**1단계: 문제 현상 심층 분석 및 정보 수집 (1시간 ~ 2시간)**

*   **문제 현상 상세 기록:**
    *   어떤 VLAN들이 통신이 안되는지 정확히 파악합니다. (VLAN ID, 멤버 포트 목록 등)
    *   루프성 트래픽이 발생하는 시점, 빈도, 양상을 기록합니다. (예: 특정 시간대, 특정 VLAN 간, 특정 시간 간격 등)
    *   문제가 발생하는 단말들의 IP 주소, OS 버전 등을 기록합니다.
    *   문제 발생 시 스위치 로그를 확인하고, 오류 메시지, 경고 메시지 등을 꼼꼼히 분석합니다.
*   **트렁크 설정 검증:**
    *   두 스위치의 트렁크 설정이 완전히 동일한지 확인합니다. (장애물 수, 802.1Q 설정, 우선순위 등)
    *   트렁크 포트에서 VLAN ID가 올바르게 학습되었는지 확인합니다. (CLI 명령어를 사용하여 확인)
*   **LLDP 정보 검증:**
    *   LLDP 정보를 통해 각 포트의 VLAN 정보가 정확하게 매핑되었는지 확인합니다.  (오류가 있다면 VLAN 설정 문제 또는 스위치 설정 오류일 수 있음)
*   **단말 간 통신 확인:**
    *   문제가 발생하는 VLAN에 속한 단말들 간의 ping, traceroute 등을 수행하여 네트워크 연결 상태를 확인합니다. (단말 자체의 문제일 가능성도 배제하지 않음)

**2단계: Juniper 스위치 설정 검토 및 점검 (2시간 ~ 4시간)**

*   **VLAN 설정 검토:**
    *   Juniper 스위치의 VLAN 설정(VLAN ID, 멤버 포트, 프로파일)이 Cisco 스위치의 설정과 일치하는지 확인합니다. (VLAN ID, 멤버 포트, 프로파일 설정 오류는 VLAN 통신 문제를 유발할 수 있음)
    *   VLAN 프로파일 설정이 올바른지 확인합니다. (STP, BPDU filtering, ACL 등)
*   **Spanning Tree Plus (STP) 설정 검토:**
    *   Juniper 스위치의 STP 설정 (STP 모드, 림우퍼/루토퍼 설정)이 올바르게 구성되었는지 확인합니다.  잘못된 STP 설정은 루프성 트래픽을 유발할 수 있습니다. (특히 림우퍼 설정은 중요)
*   **BPDU Filtering 설정 검토:**
    *   필요한 포트에서 BPDU Filtering이 활성화되어 있는지 확인합니다. (BPDU Filtering이 활성화된 포트에서 BPDU가 수신되면 STP가 제대로 작동하지 않음)
*   **ACL (Access Control List) 검토:**
    *   VLAN 간 통신을 차단하는 ACL 규칙이 있는지 확인합니다. (ACL 규칙이 잘못 구성되어 있으면 특정 VLAN 간 통신이 불가능할 수 있음)
*   **포트 설정 검토:**
    *   각 포트의 속도, 듀플렉스, 기타 설정이 올바르게 구성되었는지 확인합니다. (잘못된 설정은 링크 문제를 유발할 수 있음)

**3단계: 루프성 트래픽 발생 원인 분석 및 해결 (2시간 ~ 4시간)**

*   **Packet Capture (Wireshark 등):**
    *   루프성 트래픽이 발생하는 포트에서 Packet Capture을 수행하여 트래픽의 원인을 분석합니다. (중복된 패킷, 잘못된 MAC 주소, 잘못된 VLAN ID 등이 원인일 수 있음)
*   **STP 문제 진단:**
    *   STP 관련 메시지 (예: BPDU Storm)를 확인하여 STP 문제 (예: STP 롤백, BPDU Flood)가 있는지 진단합니다. (잘못된 STP 설정이 루프성 트래픽을 유발할 수 있음)
*   **Loop Guard 활성화:**
    *   Juniper 스위치의 Loop Guard 기능을 활성화하여 루프성 트래픽 발생을 방지합니다. (Loop Guard는 STP에서 루프를 감지하고 자동으로 대응하여 루프성 트래픽을 방지함)
*   **포트 설정 조정:**
    *   루프성 트래픽의 원인이 되는 포트 설정을 조정합니다. (예: 림우퍼 설정 변경, STP 설정 변경)

**4단계: 이전 작업 순서 (안전한 전환을 위한 권장 순서)**

1.  **기본적인 연결 확인:** 802.1Q 트렁크 설정 및 LLDP 인식 확인
2.  **VLAN 설정 검토:** Cisco 스위치와 Juniper 스위치의 VLAN 설정 일치 확인
3.  **STP 설정 검토 및 초기화:** Juniper 스위치의 STP 설정 초기화 및 점검
4.  **Loop Guard 활성화:** 루프성 트래픽 방지를 위한 Loop Guard 기능 활성화
5.  **문제 발생 시 상세 분석 및 해결:** Packet Capture, STP 문제 진단, ACL 및 포트 설정 조정
6.  **테스트 및 검증:**  문제가 해결되었는지 확인하기 위해 테스트 트래픽을 보내고, VLAN 간 통신 및 응답 시간을 측정합니다.

**주의 사항:**

*   **변경 관리:**  Juniper 스위치의 설정을 변경하기 전에 변경 사항을 문서화하고, 변경 후에는 반드시 테스트를 수행합니다.
*   **백업:**  Cisco 스위치의 설정 변경 전에 백업을 수행합니다. (필요시 이전 설정으로 복구 가능)
*   **점진적 전환:**  가능하다면 모든 트래픽을 Juniper 스위치로 전환하기 전에 일부 트래픽만 전환하여 문제 발생 시 영향을 최소화합니다.
*   **Juniper 지원:**  문제가 지속될 경우 Juniper 기술 지원에 문의하여 도움을 받습니다.

**제한 사항:**

위 답변은 제공된 정보에 기반하여 작성되었으며, 실제 문제 해결을 보장하지 않습니다.  문제의 정확한 원인을 파악하기 위해서는 추가적인 정보(예: 스위치 모델, 설정 파일, 로그 파일 등)가 필요할 수 있습니다. 또한, 네트워크 환경에 따라 문제 해결 방법이 달라질 수 있습니다.
