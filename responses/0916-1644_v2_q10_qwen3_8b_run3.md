기존 Cisco 스위치에서 Juniper 스위치로 장비 이전 중에 발생한 문제는 **VLAN 구성**, **트렁크 인터페이스 설정**, **스토리지 설정**, 그리고 **루프 방지 기능**을 중심으로 점검해야 합니다. 아래는 확인 순서와 안전한 전환 작업 순서입니다.

---

### 🔍 **점검 순서 및 확인 항목**

1. **트렁크 인터페이스 설정 확인**
   - Cisco 및 Juniper 스위치 모두에서 **trunk 포트**로 설정되었는지 확인하세요.
   - `switchport mode trunk` (Cisco), `set interfaces fe-0/0/0 unit 0 family ethernet-switching port-mode trunk` (Juniper) 등 해당 명령어가 적용되었는지 점검하세요.
   - **PVID (Port VLAN ID)** 가 맞는지 확인하세요. Cisco는 `switchport trunk native vlan` 명령어로 설정하고, Juniper는 `set interfaces fe-0/0/0 unit 0 family ethernet-switching native-vlan-id` 명령어로 설정합니다.

2. **VLAN 구성 일치 여부 확인**
   - 두 스위치에서 VLAN 정보가 **정확히 일치하는지** 확인하세요.  
     - VLAN ID, 이름, 상태 (활성/비활성), QoS 정보 등이 모두 동일해야 합니다.
     - `show vlan brief` (Cisco), `show vlan` (Juniper) 등을 통해 VLAN 정보를 확인하세요.

3. **인터페이스 연결 및 케이블 상태 확인**
   - **케이블 연결 상태**가 제대로 되었는지 확인하세요.
   - 포트에서 **link up 상태**가 되었는지, **LLDP**로 서로 인식되는지 확인합니다.  
     - `show lldp neighbors` (Cisco), `show lldp interface` (Jun, Junos CLI) 명령어를 사용합니다.

4. **스토리지 및 포워딩 설정 확인**
   - Juniper 스위치는 **STP (Spanning Tree Protocol)**를 사용하여 루프를 방지합니다.  
     - `show spanning-tree` 명령어로 STP 상태를 확인하세요.  
     - 포트가 **forwarding 상태**인지 확인하고, **blocking 상태**에 있는 포트가 없는지 확인하세요.
   - Cisco 스위치도 STP를 사용하므로, 동일하게 `show spanning-tree`를 확인하세요.

5. **VLAN별 루트 스위치 확인**
   - 루트 스위치가 정확히 설정되어 있는지 확인하세요.  
     - VLAN별로 루트 스위치가 다른 경우, **MAC 브로드캐스트 트래픽**이 발생할 수 있습니다.
     - `show spanning-tree vlan <VLAN-ID>`를 사용하면 루트 스위치를 확인할 수 있습니다.

6. **인터페이스별 VLAN 포워딩 확인**
   - 특정 VLAN이 통신되지 않는 경우, 해당 VLAN이 포트에 **사용 가능한 상태**인지 확인하세요.  
     - Cisco에서 `show interface <interface> switchport` 명령어, Juniper에서는 `show interfaces fe-0/0/0 unit 0 family ethernet-switching` 명령어로 확인 가능합니다.

7. **에러 카운트 확인**
   - `show interface <interface>` (Cisco), `show interfaces fe-0/0/0` (Juniper)를 통해 **CRC 오류**, **input/output errors**가 있는지 확인하세요.

### 🛡️ **안전한 이전 작업 순서**

1. **기존 Cisco 스위치에서 VLAN 및 인터페이스 상태 저장**
   - `show vlan`, `show running-config`, `show interfaces` 등을 통해 현재 상태를 기록해 두세요.

2. **Juniper 스위치에 VLAN 및 인터페이스 구성 동일하게 복사**
   - Cisco의 VLAN 정보와 인터페이스 설정을 Juniper에 동일하게 복사하세요.
   - 포트 모드, PVID, Native VLAN, STP 설정 등은 모두 맞춰야 합니다.

3. **트렁크 포트 구성 확인**
   - 트렁크 포트가 정확히 설정되었는지 확인하고, VLAN 구성이 일치하는지 점검하세요.

4. **STP 설정 일치 확인**
   - 두 스위치에서 STP 모드 (RSTP, MSTP 등), 루트 브리지, 패턴 등이 일치하는지 확인하세요.

5. **모든 VLAN 통신 테스트**
   - VLAN별로 통신 테스트를 진행하세요. 단말 간 통신이 정상인지 확인하고, **로깅 및 포트 기능 설정**을 확인하세요.

6. **모니터링 및 로그 확인**
   - 포트 상태, 통신 패턴, 루프 트래픽 등 **모니터링 도구**를 활용해 이상 유무를 확인하세요.

7. **다중 VLAN 사용 시 MSTP 설정**
   - 여러 VLAN이 사용되는 경우 MSTP를 사용해야 하며, **VLAN Pooling**과 **IST (Internal Spanning Tree)** 설정이 필요할 수 있습니다.

8. **전환 중 단계적 점검 및 테스트**
   - 단계별로 전환하고, 각 단계에서 통신 상태와 루프 상태를 점검해야 합니다.  
   - 문제가 발생할 경우, **역으로 복원**할 수 있도록 백업 파일과 기존 설정을 저장해야 합니다.

### 📌 **요약**

- 트렁크 설정, VLAN 구성, STP 설정, 인터페이스 포워딩 상태 등을 점검해야 합니다.
- 루프 문제는 STP 설정과 케이블 연결 상태에서 발생할 수 있습니다.
- 안전한 이전은 기존 설정을 복사하고, 단계적으로 구성하며, 테스트와 모니터링을 통해 진행해야 합니다.  
- 확실하지 않은 설정은 추측하지 말고, 명확한 확인 후 진행해야 합니다.
