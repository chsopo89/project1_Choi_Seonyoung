Cisco 스위치에서 광 SFP 모듈이 인식되지 않는 경우, 다음 명령어를 통해 상태를 확인할 수 있습니다.  
1. **`show interface status`**: 포트 상태(예: up/down, SFP 인식 여부)를 확인합니다.  
2. **`show sfp`** 또는 **`show interface transceiver`**: SFP 모듈의 제조사, 모델, 시리얼 번호, 버전 등을 확인합니다.  
3. **`show inventory`**: 하드웨어 구성 요소(포트, SFP 등)의 물리적 상태를 점검합니다.  
4. **`show diag`**: 포트의 진단 정보(예: SFP 연결 상태, 전력, 속도)를 확인합니다.  

**A/S 절차**:  
- **정품 SFP 모듈인 경우**:  
  - Cisco 지원팀에 연락하여 SFP 시리얼 번호, 스위치 모델, 오류 메시지 등을 제공해야 합니다.  
  - 지원팀은 SFP의 하드웨어/소프트웨어 문제 여부를 확인하고, 필요 시 교체 또는 재설치를 권장할 수 있습니다.  
  - Cisco의 정품 부품 교체 프로그램(Cisco Replacement Program)을 통해 무상 교체가 가능할 수 있으나, 특정 조건(예: 보증 기간, 고장 원인)에 따라 다릅니다.  

- **서드파티 SFP 모듈인 경우**:  
  - Cisco는 서드파티 SFP를 지원하지 않으므로, 해당 모듈의 제조사에 직접 문의해야 합니다.  
  - 서드파티 모듈의 경우, 보증 기간이 제한적일 수 있으며, 고장 시 해당 제조사의 A/S 정책에 따라 처리됩니다.  
  - Cisco 스위치에서 서드파티 SFP가 작동하지 않는 경우, 호환성 문제(예: 속도, 파워 등)가 원인일 수 있으므로, 제조사의 호환성 확인이 필수적입니다.  

**점검 순서**:  
1. SFP 인식 여부 확인 → 2. SFP 정보 확인 → 3. 포트 상태 점검 → 4. 스위치 소프트웨어 업데이트 확인 → 5. SFP 교체 및 재검증.  
**주의**: 명확하지 않은 설정값이나 명령어는 추측하지 않고, Cisco 공식 문서나 지원팀에 확인해야 합니다.
