FortiGate에서 로그가 생성되지 않거나 전송되지 않는 문제를 해결하려면 아래와 같은 점검 순서와 확인 항목을 따르는 것이 좋습니다.  

1. **로그 설정 검토**:  
   - **로그 유형 및 레벨**: 로그 설정에서 'System Log' 또는 'Traffic Log' 등의 로그 유형이 활성화되어 있는지 확인합니다. 레벨(예: `info`, `debug`)이 너무 높거나 낮아 특정 로그가 생성되지 않을 수 있습니다.  
   - **저장 경로**: 로그가 내부 버퍼에 저장되는 설정(`log-uuid`, `log-rotate`)이 올바르게 구성되었는지 확인합니다.  

2. **로그 전송 구성 검토**:  
   - **전송 프로필**: 'Log Forwarding' 설정에서 올바른 로그 서버(예: FortiAnalyzer, Syslog 서버)와 프로필이 연결되어 있는지 확인합니다.  
   - **프로토콜 및 포트**: 사용하는 프로토콜(UDP/TCP, Syslog, FortiAnalyzer)과 포트(예: 514, 8080)가 정확한지, 서버에 연결 가능한지 점검합니다.  

3. **네트워크 연결 확인**:  
   - **포트 통신**: 로그 전송에 필요한 포트가 네트워크 장비(예: 방화벽, 라우터)에서 차단되지 않았는지 확인합니다. `ping`은 기본적으로 ICMP 포트만 확인하므로, 로그 전송에 사용되는 포트는 별도로 검사해야 합니다.  
   - **DNS 설정**: 로그 서버의 호스트명이 정확하게 구성되었고, DNS가 정상적으로 해결되는지 확인합니다.  

4. **로그 서버 설정 검토**:  
   - **서버 수신 설정**: 로그 서버에서 FortiGate의 IP 주소 또는 호스트명을 정확하게 등록했는지, 수신 포트가 열려 있는지 확인합니다.  
   - **인증 및 암호화**: 필요한 경우 SSL/TLS 인증서나 암호화 설정이 올바르게 구성되었는지 확인합니다.  

5. **시스템 로그 및 버퍼 상태 확인**:  
   - **디버깅 명령어**: `diagnose log` 또는 `diagnose debug` 명령어로 시스템 로그나 레이어별 로그 발생 여부를 점검합니다.  
   - **버퍼 상태**: 로그 버퍼가 가득 차면 로그가 저장되지 않을 수 있으므로 `diagnose sys log buffer` 명령어로 버퍼 용량 확인합니다.  

6. **정책 및 규칙 검토**:  
   - **방화벽 정책**: 로그 전송에 필요한 트래픽이 방화벽 정책에서 차단되지 않았는지 확인합니다.  
   - **로그 필터링**: 로그 전송 프로필에서 특정 로그 유형이 필터링되었는지 확인합니다.  

**점검 순서 요약**:  
1. 로그 설정 및 유형 검토 → 2. 전송 구성 및 프로토콜 확인 → 3. 네트워크 포트 통신 점검 → 4. 로그 서버 수신 설정 확인 → 5. 시스템 로그 및 버퍼 상태 확인 → 6. 방화벽 및 필터링 설정 검토.  

모든 항목을 체계적으로 점검해야 원인을 정확히 파악할 수 있으며, 추측된 명령어나 설정값은 제외하고 명확한 확인 절차에 따라 진행해야 합니다.
