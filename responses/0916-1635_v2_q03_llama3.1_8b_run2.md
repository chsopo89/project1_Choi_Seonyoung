FortiGate에서 로그가 쌓이지 않고 로그 서버로도 전송되지 않는다면, 여러 가지 가능한 원인들을 확인하여 문제를 해결해 줍니다.

### 1. 로그 설정 확인

- **1)** 로그 설정을 확인하는 것입니다. FortiGate의 로그 설정이 구성되어야 로그가 생성되기 때문입니다. 로그 설정이 올바르게 구성되어 있는지 확인해야 합니다. 로그 설정을 수정한 후에는 설정이 저장되고 적용이 되도록 확인해야 합니다.

    ```bash
    # 로그 설정 확인 (CLI)
    get log settings
    ```

- **2)** 로그 수집 장치가 로그를 수집할 수 있도록 허용되어 있는지 확인해야 합니다. 로그 수집 장치가 로그를 수집할 수 있도록 허용되지 않으면 로그가 로그 수집 장치로 전송되지 않을 것입니다.

    ```bash
    # 로그 수집 장치 허용 설정 확인 (CLI)
    get system highavailability ha-logging
    ```

- **3)** 로그 수집 장치가 로그 수집을 수행할 수 있도록 권한이 설정되어 있는지 확인해야 합니다. 로그 수집 장치가 로그 수집을 수행할 수 있도록 허용되지 않으면 로그가 로그 수집 장치로 전송되지 않을 것입니다.

    ```bash
    # 로그 수집 권한 확인 (CLI)
    diagnose sys user list
    ```

- **4)** 로그 수집 장치에 대한 정책이 설정되어 있는지 확인해야 합니다. 로그 수집 장치에 대한 정책이 설정되지 않으면 로그가 로그 수집 장치로 전송되지 않을 것입니다.

    ```bash
    # 로그 수집 정책 확인 (CLI)
    get policy id <Policy ID> log-server
    ```

### 2. 네트워크 확인

- **1)** 로그 서버와 FortiGate 간의 네트워크가 정상적으로 연결되어 있는지 확인해야 합니다. 로그 서버와 FortiGate 간의 네트워크가 연결되지 않으면 로그가 로그 서버로 전송되지 않을 것입니다.

    ```bash
    # 로그 서버 ping 확인 (CLI)
    diagnose sys network route
    ```

- **2)** 로그 서버와 FortiGate 간의 TCP 연결이 정상적으로 설정되어 있는지 확인해야 합니다. 로그 서버와 FortiGate 간의 TCP 연결이 설정되지 않으면 로그가 로그 서버로 전송되지 않을 것입니다.

    ```bash
    # 로그 서버 TCP 연결 확인 (CLI)
    diagnose netstat -r
    ```

### 3. 로그 수집 장치 확인

- **1)** 로그 수집 장치가 로그 수집을 수행중인지 확인해야 합니다. 로그 수집 장치가 로그 수집을 수행중이지 않으면 로그가 로그 수집 장치로 전송되지 않을 것입니다.

    ```bash
    # 로그 수집 장치 확인 (CLI)
    get system highavailability ha-logging
    ```

- **2)** 로그 수집 장치가 로그를 수집할 수 있도록 허용되어 있는지 확인해야 합니다. 로그 수집 장치가 로그를 수집할 수 있도록 허용되지 않으면 로그가 로그 수집 장치로 전송되지 않을 것입니다.

    ```bash
    # 로그 수집 장치 허용 설정 확인 (CLI)
    get system highavailability ha-logging
    ```

### 확인 순서

1.  로그 설정 확인 (CLI) : 로그 설정이 올바르게 구성되어 있는지 확인합니다.
2.  로그 수집 장치 확인 (CLI) : 로그 수집 장치가 로그 수집을 수행중인지 확인합니다.
3.  로그 수집 장치 허용 설정 확인 (CLI) : 로그 수집 장치가 로그를 수집할 수 있도록 허용되어 있는지 확인합니다.
4.  로그 수집 권한 확인 (CLI) : 로그 수집 장치가 로그 수집을 수행할 수 있도록 권한이 설정되어 있는지 확인합니다.
5.  로그 수집 정책 확인 (CLI) : 로그 수집 장치에 대한 정책이 설정되어 있는지 확인합니다.
6.  로그 서버 ping 확인 (CLI) : 로그 서버와 FortiGate 간의 네트워크가 정상적으로 연결되어 있는지 확인합니다.
7.  로그 서버 TCP 연결 확인 (CLI) : 로그 서버와 FortiGate 간의 TCP 연결이 정상적으로 설정되어 있는지 확인합니다.
