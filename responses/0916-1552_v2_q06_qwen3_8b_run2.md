Cisco 스위치에서 NTP 시간 동기화가 정상적이었으나 유지보수 시 특정 스위치만 시간이 맞지 않는 문제는 다음과 같은 점을 점검해야 합니다.  

### **1. 현재 시각 확인**  
`show clock` 명령어로 스위치의 현재 시각을 확인하세요.  
- 시각이 오르는 경우, **UTC 시간**이 아닌 로컬 시간이 설정되어 있을 수 있습니다.  
- `clock timezone` 명령어로 시간대 설정을 확인하고, 필요 시 `clock summer-time` 명령어로 여름 시간 설정도 점검하세요.  

### **2. NTP 구성 및 동기화 상태 확인**  
- **NTP 서버 설정**을 확인하세요: `show running-config | include ntp server`  
  - 서버 IP가 오류 없이 입력되었는지, 동일한 서버가 다른 스위치에 정상적으로 동기화되는지 확인해야 합니다.  
- **NTP 동기화 상태**를 점검하세요: `show ip ntp status`  
  - 서버가 `synchronizing` 또는 `unsynchronized` 상태인 경우, 네트워크 연결, 서버 접근성, 또는 인증 오류가 있을 수 있습니다.  
  - `show ntp peers` 명령어로 서버와의 연결 상태(예: `reach`, `offset`, `delay`)를 확인하세요.  

### **3. 네트워크 연결 및 방화벽 설정**  
- **NTP 서버에 대한 패킷 흐름**을 확인하세요:  
  - `ping [NTP 서버 IP]`로 서버에 도달 가능한지 확인하세요.  
  - 방화벽이 **UDP 포트 123**을 차단하고 있지 않은지 확인하세요.  
- **VLAN 또는 ACL**이 특정 스위치만 차단하고 있는지 점검하세요.  

### **4. NTP 인증 및 보안 설정**  
- **NTP 인증 설정**이 활성화된 경우, 인증키가 일치하는지 확인하세요:  
  - `ntp authentication-key` 또는 `ntp authenticate` 명령어로 설정을 확인하세요.  
  - 인증 실패 시 서버와의 동기화가 중단될 수 있습니다.  

### **5. 스위치의 NTP 서비스 상태**  
- `show ip ntp configuration` 명령어로 NTP 서비스가 활성화되었는지 확인하세요.  
- `ntp server` 명령어로 설정한 서버가 실제로 적용된 상태인지 점검하세요.  

### **NTP 서버 변경 여부?**  
NTP 서버 자체가 정상임을 확인했다면, **서버 변경은 추천되지 않습니다**.  
- 서버는 이미 정상 작동 중이며, 문제는 스위치의 구성이나 네트워크 환경에 있습니다.  
- 서버 변경은 일시적 해결책일 뿐, 근본 원인을 해결하지 못합니다.  

### **결론**  
1. 현재 시각 및 시간대 설정 점검 → 2. NTP 구성 및 동기화 상태 확인 → 3. 네트워크 연결 및 방화벽 검사 → 4. 인증 설정 점검 → 5. 서비스 상태 확인 순서로 문제를 해결해야 합니다.  
NTP 서버 변경은 **확실한 원인 파악 전에 권장되지 않습니다**.
