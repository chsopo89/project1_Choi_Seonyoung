## FortiGate Virtual IP 웹 서비스 중단 문제 해결을 위한 점검 및 순서

웹 서비스가 FortiGate의 Virtual IP (VIP)를 통해 제공되면서 갑자기 중단되었고, VIP 설정, 정책, 서버, 방화벽-서버 간 통신, 서버의 외부 연결 등 기본적인 요소들은 정상으로 확인된 상황입니다. 문제는 웹 서비스 자체의 문제로 추정할 수 있으며, 문제 해결을 위해 아래와 같은 단계별로 점검하고 순서를 진행해야 합니다.

**1단계: 문제 재현 및 상세 정보 수집 (1시간 내)**

*   **문제 재현 확인:** 문제 상황이 지속적으로 발생하는지, 아니면 일시적인 문제인지 확인합니다. 여러 시간 동안 지속적으로 모니터링하여 재발 여부를 확인합니다.
*   **클라이언트 측 정보 수집:** 웹 서비스를 이용하는 클라이언트 (사용자)의 IP 주소, 사용하는 브라우저, OS 정보 등을 수집합니다. 문제 발생 시 클라이언트 환경에 따라 특정 설정이나 브라우저 문제로 인해 발생했을 가능성을 배제할 수 없습니다.
*   **FortiGate 로그 상세 확인:** 방화벽의 VIP 관련 로그 및 웹 서비스와 관련된 로그 (웹 서버 로그, FortiGate의 애플리케이션 로그 등)를 상세하게 확인합니다. 특히, 다음과 같은 로그를 집중적으로 확인합니다.
    *   VIP 설정 변경 로그
    *   정책 적용 로그
    *   웹 서비스 트래픽 로그
    *   오류 (Error) 로그
    *   경고 (Warning) 로그
    *   시스템 로그 (System Logs)
*   **FortiGate 시스템 상태 점검:** FortiGate의 CPU 사용량, 메모리 사용량, 디스크 공간 등을 확인하여 시스템 리소스 부족으로 인한 문제 발생 가능성을 배제합니다.

**2단계: FortiGate VIP 설정 및 정책 재확인 (1시간 내)**

*   **VIP 설정:** VIP 주소, 서브넷 마스크, VIP를 사용하는 FortiGate 인스턴스 등을 다시 한번 꼼꼼하게 확인합니다. 설정 값에 오타나 잘못된 설정이 없는지 확인합니다.
*   **정책 설정:** VIP를 대상으로 하는 정책 (웹 서비스 트래픽에 대한 규칙)을 다시 확인합니다. 특히, 다음과 같은 사항을 검토합니다.
    *   정책 우선순위 (Policy Priority)
    *   프로토콜 (TCP/UDP)
    *   포트 (Port)
    *   대상 IP 주소 (Destination IP Address)
    *   타임아웃 (Timeout) 설정
    *   웹 서비스의 특성 (HTTPS, HTTP 등)에 맞는 정책 설정인지 확인합니다.
*   **NAT 설정:** VIP를 사용한 NAT 설정이 올바르게 구성되어 있는지 확인합니다. NAT 관련 설정 오류는 웹 서비스 접속을 방해할 수 있습니다.

**3단계: FortiGate 애플리케이션 및 서비스 확인 (1-2시간)**

*   **웹 서비스 애플리케이션 상태:** FortiGate에 적용된 웹 서비스 애플리케이션의 상태를 확인합니다. FortiGate의 애플리케이션 뷰에서 웹 서비스가 정상적으로 실행 중인지, 오류가 발생하고 있는지 확인합니다.
*   **FortiGate Service 설정:** 웹 서비스 관련 FortiGate Service 설정 (예: 웹 서버 설정, HTTP/HTTPS 설정 등)을 확인합니다. 서비스 설정이 올바르게 구성되어 있는지, 필요한 설정이 빠진 부분은 없는지 확인합니다.
*   **FortiGate Firmware 버전:** FortiGate의 Firmware 버전이 최신인지 확인합니다. 오래된 Firmware 버전은 보안 취약점이나 버그로 인해 웹 서비스에 영향을 줄 수 있습니다.
*   **FortiGate 설정 초기화:** 문제가 지속될 경우, FortiGate의 VIP 설정 및 관련 설정을 초기화하는 것을 고려합니다. (주의: 초기화 시 설정 정보가 모두 사라지므로, 백업 후 진행해야 합니다.)

**4단계: 웹 서버 심층 점검 (2-4시간)**

*   **웹 서버 로그 분석:** 웹 서버의 로그 파일 (access log, error log 등)을 상세하게 분석하여 문제의 원인을 파악합니다. 특히, 다음과 같은 오류 메시지를 집중적으로 확인합니다.
    *   500 Internal Server Error
    *   403 Forbidden
    *   404 Not Found
    *   Timeout Error
*   **웹 서버 설정 확인:** 웹 서버의 설정 파일 (httpd.conf, virtual host 설정 등)을 확인하여 웹 서비스가 정상적으로 동작하도록 설정되어 있는지 확인합니다.
*   **웹 서버 프로세스 상태 확인:** 웹 서버 프로세스의 상태를 확인하여 정상적으로 실행 중인지, 프로세스에 문제가 있는지 확인합니다.
*   **웹 서버 리소스 사용량 확인:** 웹 서버의 CPU, 메모리, 디스크 I/O 사용량을 확인하여 리소스 부족으로 인한 문제 발생 가능성을 배제합니다.

**5단계: 네트워크 트래픽 분석 (2-4시간)**

*   **패킷 캡처:** 방화벽 또는 네트워크 스위치에서 웹 서버와 VIP 간의 트래픽을 캡처합니다. 캡처된 패킷을 분석하여 통신 과정에서 발생하는 문제 (패킷 손실, 응답 지연 등)를 파악합니다.
*   **Wireshark 사용:** 캡처된 패킷을 Wireshark와 같은 패킷 분석 도구를 사용하여 상세하게 분석합니다.

**확인 및 추측 금지:**

위에 제시된 단계들을 진행하면서 "확실하지 않은 명령어나 설정값은 추측하지 말고 모른다고 하세요"라는 지침을 철저히 지켜야 합니다. FortiGate의 설정 정보는 상황에 따라 달라질 수 있으며, 잘못된 추측은 문제 해결을 더욱 어렵게 만들 수 있습니다.

**주의 사항:**

*   문제 해결 과정에서 FortiGate의 설정을 변경하기 전에 반드시 백업을 수행합니다.
*   문제 해결 과정에서 발생하는 모든 변경 사항을 기록합니다.
*   문제가 해결되지 않을 경우, Fortinet 기술 지원팀에 문의하여 도움을 받습니다.

**추가적으로 고려해야 할 사항:**

*   웹 서비스가 특정 시간대에만 중단되는 경우, 해당 시간대에 특정 트래픽이 집중되는지 확인합니다.
*   웹 서비스의 업데이트 또는 패치가 최근에 적용된 경우, 업데이트 또는 패치로 인해 웹 서비스에 문제가 발생했을 가능성을 고려합니다.

위의 점검 순서를 통해 문제의 원인을 파악하고 웹 서비스를 복구할 수 있기를 바랍니다.
