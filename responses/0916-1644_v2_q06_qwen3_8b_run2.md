NTP 설정이 정상이었지만, 유지보수 시 특정 스위치에서 시간이 틀어진 경우, 우선 확인해야 할 항목은 **NTP 클라이언트 설정**과 **NTP 서버 동기화 상태**입니다. 먼저 스위치에서 다음 명령어로 현재 NTP 설정을 확인해야 합니다.

```
show ntp status
show ntp associations
show ntp server
show clock
```

**`show ntp status`** 명령어는 NTP 클라이언트가 정상적으로 동기화되고 있는지 확인해 줍니다. **`show ntp associations`**는 NTP 서버와의 연결 상태를 보여주며, 서버가 정상적으로 응답하고 있는지 확인할 수 있습니다. **`show ntp server`**는 설정된 NTP 서버 목록을 확인하며, **`show clock`**은 스위치의 현재 시스템 시간을 보여줍니다.

만약 NTP 서버가 정상적으로 응답하고 있으며, 다른 스위치에서 정상적으로 동기화되는 경우, 문제는 해당 스위치의 **NTP 클라이언트 설정**에 있을 가능성이 큽니다. 예를 들어, 스위치가 특정 NTP 서버에만 연결되어 있고, 해당 서버가 오작동하거나 네트워크 장애가 발생한 경우, 그 스위치는 정상적으로 동기화되지 않을 수 있습니다. 이 경우, NTP 서버를 변경하는 것은 올바른 접근법일 수 있지만, 우선 원인을 명확히 파악해야 합니다.

NTP 서버를 변경하는 것이 맞는 접근인지 판단하기 위해서는, **모든 스위치가 동일한 NTP 서버를 사용하는지**, **NTP 서버가 안정적인지**, **네트워크 경로에 문제가 없는지** 등을 확인해야 합니다. 만약 NTP 서버 자체가 문제가 없는 상태에서, 특정 스위치만 시간이 틀어진다면, 해당 스위치의 설정이나 네트워크 연결 상태를 점검하는 것이 우선입니다. 

확실하지 않은 설정이나 명령어는 추측하지 말고, **현 상태를 정확히 확인**하는 것이 중요합니다.
