## Cisco 스위치에서 Juniper 스위치로 장비 이전 시 문제 해결 및 안전한 전환 절차

현재 상황은 Cisco 스위치에서 Juniper 스위치로 장비를 이전하는 과정에서 발생한 문제로 보이며, 802.1Q 트렁크 설정과 VLAN ID 일치, LLDP 링크 인식은 기본적인 네트워크 연결이 정상적으로 이루어졌음을 의미합니다. 그러나 일부 VLAN만 통신이 되지 않고 간헐적인 루프성 트래픽이 발생하고 있다는 점은 문제 해결의 핵심입니다.

**1. 문제 분석 및 우선순위 설정**

*   **문제 심각성:** 간헐적인 루프성 트래픽은 네트워크 성능 저하 및 서비스 중단으로 이어질 수 있으므로 즉각적인 조치가 필요합니다.
*   **문제 범위:** 일부 VLAN만 통신이 안 된다는 점은 문제의 원인이 특정 VLAN 설정이나 트래픽 흐름에 있을 가능성을 시사합니다.
*   **증상 분석:**
    *   **통신 불가능한 VLAN:** 해당 VLAN에 속한 장비는 어떤 증상을 보이는지, 어떤 네트워크 서비스에 영향을 받는지 파악합니다.
    *   **루프성 트래픽:** 루프성 트래픽이 발생하는 시간, 빈도, 발생 위치 등을 꼼꼼하게 기록합니다.
    *   **단말 간 통신:** 각 스위치 내부에서 단말 간 통신이 정상적으로 이루어지는 경우, 트렁크 설정이나 VLAN ID 문제보다는 다른 문제 (예: ACL, STP 등)일 가능성이 높습니다.

**2. 점검 및 확인 사항 (단계별 접근)**

아래는 문제 해결을 위한 점검 및 확인 사항을 단계별로 제시합니다. 각 단계를 진행하면서 문제를 좁혀나가야 합니다.

**단계 1: 기본 설정 확인**

1.  **트렁크 설정 재확인:** Cisco와 Juniper 스위치 모두 802.1Q 트렁크 설정이 정확하게 일치하는지 확인합니다.
    *   `show interface <포트 번호>` 명령어를 통해 트렁크 설정 (802.1Q, VLAN ID)이 정상적으로 설정되어 있는지 확인합니다.
    *   두 스위치 간 트렁크 설정이 일치하는지 비교합니다.
2.  **VLAN 설정 재확인:** VLAN ID가 Cisco와 Juniper 스위치 모두 동일하게 설정되어 있는지 확인합니다.
    *   `show vlan brief` 명령어를 통해 VLAN ID가 일치하는지 확인합니다.
3.  **포트 상태 확인:** Cisco와 Juniper 스위치 모두 문제 발생 포트의 상태를 확인합니다.
    *   `show interface <포트 번호>` 명령어를 통해 포트 상태 (상태, 속도, Duplex, Auto-Negotiation)가 정상인지 확인합니다.
    *   포트가 활성화되어 있는지 (enabled) 확인합니다.
4.  **STP (Spanning Tree Protocol) 설정 확인:** STP 설정이 올바르게 구성되어 있는지 확인합니다.
    *   Cisco 스위치에서는 `show spanning-tree` 명령어를 사용하여 STP 상태를 확인합니다.
    *   Juniper 스위치에서는 `show spanning-tree` 명령어를 사용하여 STP 상태를 확인합니다.
    *   STP 포트 상태 (Forwarding, Blocking)가 예상과 일치하는지 확인합니다.

**단계 2: 고급 설정 점검**

1.  **ACL (Access Control List) 확인:** Cisco와 Juniper 스위치 모두 ACL 설정이 문제 VLAN 통신을 방해하지 않는지 확인합니다.
    *   `show ip access-list` 명령어를 통해 ACL 설정 내용을 확인합니다.
    *   문제 VLAN에 대한 ACL 규칙이 존재하지 않는지 확인합니다.
2.  **MAC 주소 테이블 확인:** 두 스위치의 MAC 주소 테이블이 서로 일치하는지 확인합니다.
    *   `show mac address-table` 명령어를 통해 MAC 주소 테이블 내용을 확인합니다.
    *   MAC 주소 테이블에 불일치가 발생하는 경우, 스위치 간 MAC 주소 학습이 정상적으로 이루어지고 있는지 확인합니다.
3.  **라우팅 프로토콜 확인:** 라우팅 프로토콜(RIP, OSPF 등)을 사용하는 경우, 라우팅 테이블이 올바르게 구성되어 있는지 확인합니다.
    *   라우팅 프로토콜 설정 오류로 인해 문제가 발생할 수 있습니다.
4.  **MTU (Maximum Transmission Unit) 설정 확인:** MTU 설정이 스위치 간에 일치하는지 확인합니다.
    *   MTU 설정 불일치는 패킷 손실 및 루프성 트래픽 발생의 원인이 될 수 있습니다.
    *   `show interface <포트 번호>` 명령어를 통해 MTU 설정이 정상인지 확인합니다.

**단계 3: Juniper 스위치 특정 설정 점검**

1.  **VRF (Virtual Routing and Forwarding) 설정 확인:** VRF를 사용하는 경우, VRF 설정이 올바르게 구성되어 있는지 확인합니다.
2.  **선 포트 설정 확인:** 트렁크 포트가 선 포트로 설정되어 있는지 확인합니다. (선 포트는 자동으로 VLAN을 학습하므로, 잘못 설정하면 문제가 발생할 수 있습니다.)
3.  **VTP (Virtual Trunking Protocol) 설정 확인:** VTP 설정이 올바르게 구성되어 있는지 확인합니다.
    *   VTP 설정 오류는 VLAN 정보 불일치를 야기할 수 있습니다.
4.  **Junos OS 버전 확인:** Juniper 스위치의 Junos OS 버전이 최신 버전인지 확인합니다.
    *   버전 문제로 인해 일부 기능이 제대로 작동하지 않거나 보안 취약점이 존재할 수 있습니다.

**3. 안전한 전환 절차 (권장 순서)**

1.  **기존 네트워크 백업:** 전환 전에 기존 네트워크 설정을 백업합니다.
2.  **테스트 환경 구축:** 가능한 한 테스트 환경을 구축하여 새로운 Juniper 스위치를 먼저 테스트합니다.
3.  **단계적 전환:**
    *   **최소 영향 VLAN 먼저 전환:** 트래픽 양이 적고 중요도가 낮은 VLAN부터 Juniper 스위치로 전환합니다.
    *   **모니터링 강화:** 전환 중에는 네트워크 트래픽, 포트 상태, 성능 등을 면밀하게 모니터링합니다.
    *   **문제 발생 시 롤백:** 문제가 발생하면 즉시 기존 설정으로 롤백합니다.
4.  **전체 전환:** 모든 VLAN을 전환한 후에도 지속적으로 모니터링합니다.

**주의 사항:**

*   **명령어는 스위치 모델 및 Junos OS 버전에 따라 다를 수 있습니다.**
*   **실행하기 전에 반드시 스위치 설명서를 참고하여 정확한 명령어를 사용해야 합니다.**
*   **변경 사항을 적용하기 전에 반드시 테스트 환경에서 먼저 검증해야 합니다.**

**추가 정보:**

*   Juniper 스위치에서 802.1Q 트렁크를 설정하는 방법은 Cisco 스위치와 다를 수 있습니다. Juniper 스위치 설명서를 참고하여 정확한 설정 방법을 확인해야 합니다.
*   루프성 트래픽은 STP 설정 오류, ACL 설정 오류, MAC 주소 테이블 불일치 등 다양한 원인으로 발생할 수 있습니다. 문제 해결을 위해서는 원인을 정확하게 파악하고 해결해야 합니다.
