## FortiGate Virtual IP 웹 서비스 중단 문제 진단 및 점검

VIP(Virtual IP)를 통해 제공하던 웹 서비스가 갑자기 중단된 상황은 매우 복잡하고 다양한 원인이 있을 수 있습니다. 제시된 정보(VIP 설정 정상, 정책 정상, 서버 이상 없음, 방화벽-서버 간 통신 정상, 서버 외부 통신 정상)를 바탕으로 문제 해결을 위한 체계적인 접근 방식을 제시합니다.

**1. 문제 정의 및 초기 단계 점검 (1시간 이내)**

*   **문제 재확인:** 웹 서비스 중단 시간, 중단 시점의 네트워크 상태 변화, 사용자 증상(특정 사용자, 특정 시간대 등)을 명확히 파악합니다.
*   **VIP 설정 재확인:** FortiGate 웹 UI 또는 CLI를 통해 VIP IP 주소, VIP 네트워크 범위, VIP 설정이 현재 정상으로 적용되었는지 (연결 상태, 방화벽 정책 등) 다시 한번 확인합니다. 특히, VIP 설정 변경 이력이 있는지 확인합니다.
*   **방화벽 정책 재확인:** VIP와 관련된 모든 방화벽 정책(웹 서비스 방향, 프로토콜, 포트, QoS 등)이 정상적으로 구성되어 있는지 확인합니다. 정책의 오목성(lateness) 설정도 중요하며, 예상치 못한 정책이 활성화되었는지 확인합니다.
*   **로그 확인:** FortiGate의 로그(시스템 로그, IPS 로그, Web Filter 로그, Application Control 로그 등)에서 VIP 관련 이벤트(연결 시도, 접속 거부, 오류 메시지 등)를 집중적으로 확인합니다. 오류 메시지, 연결 시도 실패 횟수, 시간 등을 기록합니다.
*   **서버 상태 확인:** 웹 서버 자체의 상태를 다시 한번 확인합니다. CPU, 메모리, 디스크 사용량, 프로세스 상태 등을 모니터링하여 과부하 또는 예기치 않은 프로세스가 실행되고 있는지 확인합니다.

**2. 네트워크 트래픽 분석 (2-4시간 이내)**

*   **패킷 캡처 (Packet Capture):** FortiGate 방화벽에서 웹 서버로 향하는 트래픽을 캡처합니다. Wireshark 등의 패킷 분석 도구를 사용하여 다음과 같은 사항을 분석합니다.
    *   **SYN/ACK 손실:** 웹 서버로 향하는 TCP SYN 패킷이 제대로 ACK로 응답받지 못하는지 확인합니다. 이는 방화벽의 QoS 설정, 네트워크 혼잡, 웹 서버의 연결 제한 등으로 인해 발생할 수 있습니다.
    *   **오류 플래그:** TCP 핸드셰이크 과정에서 오류 플래그(ECE, ACK, SYN, LOSS, etc.)가 발생하고 있는지 확인합니다. 이는 네트워크 문제, 방화벽 설정 문제, 웹 서버 문제 등을 나타낼 수 있습니다.
    *   **패킷 크기:**  패킷 크기가 예상 범위를 벗어나는지 확인합니다. 방화벽 설정(MTU, MSS clamping 등) 또는 웹 서버 설정 문제일 수 있습니다.
    *   **헤더 정보:** TCP 헤더의 시퀀스 번호, 확인섬(checksum) 등을 확인하여 패킷 손상 여부를 확인합니다.
*   **네트워크 혼잡 분석:** 네트워크 모니터링 도구(PRTG, SolarWinds 등)를 사용하여 네트워크 구간의 혼잡도를 분석합니다. 특정 시간대에 혼잡도가 급증하여 웹 서비스 성능 저하를 유발할 수 있습니다.

**3. 고급 진단 및 설정 점검 (4-8시간 이내)**

*   **QoS (Quality of Service) 설정 점검:** FortiGate의 QoS 설정이 웹 서비스 트래픽에 영향을 미치는지 확인합니다. QoS 설정이 잘못 구성되면 웹 서비스 트래픽이 우선적으로 처리되지 못하고 성능 저하를 유발할 수 있습니다. 특히, 웹 서비스 트래픽에 대한 QoS 정책이 활성화되어 있는지, 그리고 해당 정책의 설정(상대적 우선순위, 제한 속도 등)이 정상인지 확인합니다.
*   **Deep Packet Inspection (DPI) 설정 점검:** FortiGate의 DPI 설정이 웹 서비스 트래픽을 잘못 식별하거나 차단하고 있는지 확인합니다. DPI 설정이 잘못 구성되면 웹 서비스 연결이 거부될 수 있습니다.
*   **방화벽 정책 재정렬:** 방화벽 정책의 순서가 웹 서비스 트래픽에 영향을 미칠 수 있습니다. 정책의 순서를 변경하여 문제가 해결되는지 확인합니다.
*   **Web Filter 설정 점검:** Web Filter 설정이 특정 웹사이트 또는 URL에 대한 접근을 차단하고 있는지 확인합니다. Web Filter 설정이 잘못 구성되면 웹 서비스 접속이 불가능해질 수 있습니다.
*   **Application Control 설정 점검:** Application Control 설정이 특정 웹 서비스에 대한 접근을 차단하고 있는지 확인합니다. Application Control 설정이 잘못 구성되면 웹 서비스 접속이 불가능해질 수 있습니다.
*   **FortiGate Firmware 버전 점검:** FortiGate의 Firmware 버전이 최신 버전인지 확인합니다. 오래된 Firmware 버전은 버그가 존재하여 웹 서비스에 영향을 줄 수 있습니다.

**4. 추가 점검 사항 및 문제 해결**

*   **FortiGate 시스템 리소스 점검:** FortiGate의 CPU, 메모리, 디스크 사용량을 모니터링합니다. 시스템 리소스가 과부하되면 웹 서비스 성능 저하를 유발할 수 있습니다.
*   **FortiGuard Threat Intelligence 업데이트:** FortiGuard Threat Intelligence 데이터베이스가 최신 버전인지 확인합니다. 오래된 Threat Intelligence 데이터베이스는 악성 트래픽을 제대로 탐지하지 못할 수 있습니다.
*   **FortiGate 재부팅:** FortiGate를 재부팅하여 일시적인 문제를 해결합니다.
*   **다른 VIP 설정 확인:** 다른 VIP 설정도 유사한 문제 증상을 보이는지 확인하여 문제의 범위를 좁힙니다.

**주의 사항:**

*   위에 제시된 점검 항목은 일반적인 경우를 기준으로 작성되었습니다. 실제 문제 해결을 위해서는 네트워크 환경, 웹 서비스 구성, FortiGate 모델 등을 고려하여 점검 항목을 조정해야 합니다.
*   문제 해결 과정에서 얻은 정보를 바탕으로 문제의 원인을 추론하고, 필요한 설정을 변경합니다.
*   문제 해결이 어려운 경우, Fortinet 기술 지원팀에 문의하여 도움을 받으십시오.
