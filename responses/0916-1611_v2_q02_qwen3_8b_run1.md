FortiGate의 Virtual IP(VIP)를 통해 제공하던 웹 서비스가 중단된 경우, 다음 단계를 점검해야 합니다.  

### 1. **VIP 설정 점검**  
- **포트 전달 설정 확인**: VIP가 웹 서비스가 사용하는 포트(예: HTTP 80, HTTPS 443)에 올바르게 매핑되었는지 확인하세요. `config vip` 명령어로 설정을 확인하고, `port` 값이 서버에서 실제로 사용하는 포트와 일치하는지 확인해야 합니다.  
- **NAT 구성 확인**: VIP의 `snat` 또는 `dnat` 설정이 적절한지 확인하세요. 예를 들어, `dnat`가 서버의 내부 IP로 설정되었는지 확인합니다.  

### 2. **정책 및 규칙 점검**  
- **프록시/패킷 필터링 정책**: 웹 서비스용 포트(80, 443)가 정책에서 허용되었는지 확인하세요. `config firewall policy` 명령어로 확인합니다.  
- **애플리케이션 제어 프로필**: HTTP/HTTPS 트래픽이 허용된 프로필이 적용되었는지 확인하세요. `config application control profile` 명령어로 확인하고, 애플리케이션 제어 정책이 HTTP/HTTPS 트래픽을 차단하지 않았는지 확인합니다.  

### 3. **서버 구성 확인**  
- **서버 포트 리스닝 상태**: 서버에서 웹 서비스가 해당 포트(예: 80, 443)에서 리스닝 중인지 확인하세요. `netstat -an | grep :80` 또는 `ss -tuln` 명령어로 확인합니다.  
- **인터페이스 바인딩**: 서버의 웹 서버(예: Apache, Nginx)가 외부 IP(0.0.0.0) 또는 내부 IP에 바인딩되어 있는지 확인하세요. `bind` 설정이 올바르게 구성되었는지 확인합니다.  

### 4. **트래픽 경로 및 로그 분석**  
- **트래픽 로그 확인**: `diagnose firewall flow table` 또는 `diagnose firewall log` 명령어로 웹 트래픽이 방화벽을 통해 전달되는지 확인합니다.  
- **서버 로그 분석**: 웹 서버의 접근 로그(예: /var/log/apache2/access.log)에서 외부 요청이 도착했는지 확인합니다. 요청이 없으면 방화벽 정책 또는 네트워크 설정 문제일 수 있습니다.  

### 5. **SSL/TLS 문제 확인**  
- **HTTPS 서비스**: HTTPS 서비스가 작동하려면 서버가 SSL/TLS 인증서를 올바르게 구성해야 합니다. `openssl s_client -connect <서버IP>:443` 명령어로 SSL 연결이 성공하는지 확인합니다.  

### 6. **외부 접근 테스트**  
- **외부 네트워크에서 테스트**: 다른 네트워크에서 웹 서비스에 접근해 보세요. 방화벽의 NAT 구성이 외부 IP를 올바르게 전달하는지 확인합니다.  

위 절차를 통해 VIP 구성, 정책, 서버 설정, 트래픽 경로 등을 체계적으로 점검해야 합니다. 명확하지 않은 설정이나 추측은 피하고, 실제 로그와 구성 검증을 우선적으로 수행해야 합니다.
