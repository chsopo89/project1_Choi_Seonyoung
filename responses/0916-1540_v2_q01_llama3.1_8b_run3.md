FortiGate의 IPsec VPN이 연결되고 라우팅이 정상인 경우, Phase 1과 Phase 2 사이에서 발생하는 로그인 경우에는 다음의 사항을 확인해야 합니다.

1. **IPsec VPN 구성**: IPsec VPN 구성이 올바르게 구성되었는지 확인합니다. IPsec VPN 설정에서 IKE (Internet Key Exchange) 및 ESP (Encapsulating Security Payload) 구성이 올바른지 확인합니다.

2. **IKE Negotiation**: IKE negotiation 과정에서 문제가 발생하지 않는지 확인합니다. IKE negotiation 실패의 원인으로는 Peer ID 또는 Certificate 관련 문제가 있을 수 있습니다.

3. **ESP Negotiation**: ESP negotiation 과정에서 문제가 발생하지 않는지 확인합니다. ESP negotiation 실패의 원인으로는 Peer ID 또는 Certificate 관련 문제가 있을 수 있습니다.

4. **DH Group Negotiation**: DH Group Negotiation 과정에서 문제가 발생하지 않는지 확인합니다. DH Group Negotiation 실패의 원인으로는 Peer ID 또는 Certificate 관련 문제가 있을 수 있습니다.

5. **Hash Algorithm Negotiation**: Hash Algorithm Negotiation 과정에서 문제가 발생하지 않는지 확인합니다. Hash Algorithm Negotiation 실패의 원인으로는 Peer ID 또는 Certificate 관련 문제가 있을 수 있습니다.

6. **ESP Protocol Negotiation**: ESP Protocol Negotiation 과정에서 문제가 발생하지 않는지 확인합니다. ESP Protocol Negotiation 실패의 원인으로는 Peer ID 또는 Certificate 관련 문제가 있을 수 있습니다.

7. **IPsec SA Negotiation**: IPsec SA Negotiation 과정에서 문제가 발생하지 않는지 확인합니다. IPsec SA Negotiation 실패의 원인으로는 Peer ID 또는 Certificate 관련 문제가 있을 수 있습니다.

8. **IKE SA Negotiation**: IKE SA Negotiation 과정에서 문제가 발생하지 않는지 확인합니다. IKE SA Negotiation 실패의 원인으로는 Peer ID 또는 Certificate 관련 문제가 있을 수 있습니다.

9. **Certificate 관련 문제**: Certificate 관련 문제가 있는지 확인합니다. Peer ID 또는 Certificate 관련 문제가 있으면 IPsec VPN이 연결되지 않습니다.

10. **FortiGate Firmware**: FortiGate Firmware가最新인지 확인합니다.最新의 Firmware가 적용된 경우 문제가 발생하지 않습니다.

11. **시스템 자원**: 시스템 자원이 충분한지 확인합니다. 시스템 자원이 부족한 경우 IPsec VPN이 연결되지 않습니다.

12. **네트워크 환경**: 네트워크 환경이 이상이 없는지 확인합니다. 네트워크 환경이 이상이 있다면 IPsec VPN이 연결되지 않습니다.
