Cisco 스위치에서 NTP 설정이 정상이었지만, 유지보수 시 한 대만 시간이 어긋나는 경우, 다음과 같은 항목을 점검해야 합니다.

1. **NTP 클라이언트 설정 확인**: 스위치에서 NTP 서버 주소, 구독 범위, 인증 설정이 제대로 구성되어 있는지 확인해야 합니다.  
   - `show ntp associations` 명령어로 NTP 서버와의 연결 상태를 확인합니다.  
   - `show running-config | include ntp` 명령어로 NTP 설정을 다시 확인하세요.  
   - 특히, NTP 서버가 여러 대인 경우, 특정 스위치만 문제가 나는 경우 서버 주소나 구독 범위 설정이 잘못되었을 수 있습니다.

2. **NTP 동기화 상태 확인**:  
   - `show ntp status` 명령어로 NTP 동기화 상태를 확인합니다.  
   - 이 명령어는 NTP 클라이언트가 서버와 정확히 동기화 되었는지를 보여주며, "synchronized" 상태가 있는지 확인해야 합니다.

3. **시간 서버의 정확성 확인**:  
   - NTP 서버 자체가 정확한 시간을 제공하지 않는 경우, 스위치도 문제가 발생할 수 있습니다.  
   - `show ntp server` 명령어로 서버의 현재 시간을 확인합니다.  
   - 하지만 이 명령어는 일부 버전에서 사용할 수 없기 때문에, 직접 서버의 시간을 확인해야 할 수도 있습니다.  

4. **NTP 인증 설정 확인**:  
   - 인증 설정이 활성화되어 있고, 해당 스위치가 인증을 통과하지 못한 경우 동기화되지 않을 수 있습니다.  
   - `show ntp authentication` 명령어로 인증 상태를 확인합니다.  
   - 특히, 인증 키나 패스워드가 잘못 설정된 경우, 해당 스위치만 문제가 생길 수 있습니다.

5. **시계 오류 또는 편차 확인**:  
   - `show clock` 명령어로 현재 스위치의 시계를 확인합니다.  
   - `show ntp offset` 명령어로 NTP 서버와의 시간 편차를 확인합니다.  
   - 이 편차가 상당히 크면, 동기화가 실패하거나 지연이 있을 수 있습니다.

6. **NTP 서버 변경 여부**:  
   - NTP 서버를 변경하는 것은 문제 해결의 일부일 수 있으나, 반드시 해당 스위치의 설정 오류를 먼저 확인한 후에 시행하는 것이 좋습니다.  
   - 서버 변경 전에 위의 점검 항목을 체크하고, 해당 스위치의 설정이 정확한지 확인해야 합니다.  
   - 서버 변경은 서버의 시간 정확도나 가용성 문제가 있을 경우의 해결책일 수 있으나, 우선적으로 스위치 설정을 점검하는 것이 중요합니다.

**결론**: NTP 서버 자체는 정상이지만, 한 대만 시간이 어긋나는 경우, 해당 스위치의 NTP 설정, 동기화 상태, 인증 설정, 시계 오류 등을 확인해야 합니다. NTP 서버를 변경하는 것은 해결 방법 중 하나일 수 있지만, 우선 스위치 자체의 설정 문제를 점검하는 것이 더 적절합니다. 확실하지 않은 설정이나 명령어는 추측하지 않고, 명확한 점검 순서를 따르는 것이 좋습니다.
