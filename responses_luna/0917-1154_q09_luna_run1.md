Cisco 정품이라도 **스위치 모델·포트 속도·지원 SFP 목록·IOS/IOS XE 버전**이 맞지 않으면 인식되지 않을 수 있습니다. 아래 순서로 확인하십시오. 명령어는 플랫폼에 따라 일부 차이가 있습니다.

## 1. 포트와 SFP가 물리적으로 맞는지 확인

먼저 다음을 확인합니다.

- SFP가 포트에 끝까지 삽입되었는지
- 동일 규격인지: 1G SFP, 10G SFP+, 25G SFP28 등
- 해당 포트가 실제로 SFP를 지원하는지
- 포트가 고정형인지, 속도 변환을 지원하는지
- 광모듈과 광케이블의 파장·싱글모드/멀티모드가 일치하는지
- 다른 정상 SFP 또는 다른 정상 포트에서 교차 시험

포트의 링크 및 관리 상태를 확인합니다.

```text
show interfaces status
show interfaces <interface>
show interfaces description
```

예:

```text
show interfaces GigabitEthernet1/0/1
```

`administratively down`이면 다음과 같이 활성화합니다.

```text
interface GigabitEthernet1/0/1
 no shutdown
```

단, SFP 미인식 문제와 단순 링크 다운 문제를 구분해야 합니다.

## 2. 스위치가 SFP 자체를 인식하는지 확인

일반적인 IOS/IOS XE 스위치에서는 다음 명령을 사용합니다.

```text
show inventory
show inventory raw
show interfaces transceiver
show interfaces transceiver detail
```

일부 장비에서는 다음 명령도 사용할 수 있습니다.

```text
show idprom interface <interface>
```

확인할 내용은 다음과 같습니다.

- SFP 제조사
- PID(Product ID)
- VID
- 일련번호
- 광 파장과 지원 거리
- DOM/DDM 정보
- `unsupported`, `unknown`, `not present` 등의 메시지

`show inventory`에 해당 SFP가 전혀 표시되지 않으면, 접촉 불량·SFP 고장·포트 하드웨어 문제 가능성이 있습니다. 다른 정상 SFP를 같은 포트에 넣어 비교하고, 문제가 되는 SFP를 다른 정상 포트에서 시험하십시오.

## 3. 로그와 비활성화 상태 확인

```text
show logging
show interfaces status err-disabled
show errdisable recovery
```

로그에서 다음과 같은 내용을 찾습니다.

- unsupported transceiver
- invalid transceiver
- SFP not present
- GBIC security
- err-disabled
- link flap

플랫폼에 따라 SFP 관련 상세 정보 명령이 다르므로, 다음 정보도 확보합니다.

```text
show version
show inventory
show tech-support
```

`show tech-support`는 출력량이 많으므로 TAC나 유지보수 업체에 전달할 때 사용하십시오.

## 4. 호환성과 소프트웨어 확인

Cisco 정품이라는 사실만으로 모든 Cisco 스위치에서 사용 가능한 것은 아닙니다.

다음을 확인해야 합니다.

- 해당 스위치 모델이 그 SFP PID를 지원하는지
- 해당 포트가 해당 속도와 광 규격을 지원하는지
- 장비의 IOS/IOS XE 버전에서 해당 SFP가 지원되는지
- SFP가 단종(EoL)되었거나 특정 장비 전용인지
- Cisco의 해당 플랫폼 지원 매트릭스에 포함되는지

정확한 지원 여부는 **스위치 모델, 포트 번호, SFP PID, IOS/IOS XE 버전**으로 Cisco 공식 호환성 문서에서 확인해야 합니다. 이 정보 없이 `service unsupported-transceiver` 같은 설정을 임의로 적용하는 것은 권장하지 않습니다. 특히 정품 SFP인데도 인식되지 않는 경우에는 설정 변경보다 교차 시험과 하드웨어 판정이 우선입니다.

## 5. Cisco 정품 SFP의 A/S 절차

Cisco 유지보수 계약이 있는 경우:

1. `show version`, `show inventory`, 관련 포트 출력과 로그 수집
2. 구매처 또는 Cisco TAC에 케이스 접수
3. TAC의 호환성 및 장애 진단 수행
4. SFP 불량으로 판정되면 계약 조건에 따라 RMA 또는 교체 진행

유지보수 계약이 없더라도 제품 보증 기간과 구매 경로에 따라 보증 교환이 가능할 수 있습니다. 다만 SFP가 스위치 본체와 별도 구매된 제품인지, 보증이 끝났는지, Cisco 정식 유통 경로인지에 따라 절차와 비용이 달라집니다. 따라서 **Cisco 계약번호, SFP 일련번호, 구매 증빙, 대리점 정보**를 준비해 구매처 또는 Cisco 지원 창구에 문의해야 합니다.

## 서드파티 SFP를 사용하는 경우

서드파티 모듈은 일반적으로 다음 방식으로 처리합니다.

- SFP 자체 불량: 서드파티 제조사 또는 판매처에 RMA 요청
- 스위치 포트 또는 Cisco 소프트웨어 문제: Cisco TAC에 문의 가능하나, 서드파티 SFP가 원인으로 의심되면 지원이 제한될 수 있음
- Cisco 장비 고장으로 교체가 필요해도, Cisco가 서드파티 모듈로 인한 문제라고 판단하면 해당 모듈 제거와 정품 모듈 재시험을 요구할 수 있음

실무적으로는 **서드파티 SFP 제거 → Cisco 지원 SFP 장착 → 동일 포트에서 재시험**하여 원인을 분리합니다. 서드파티를 계속 사용하려면 해당 모듈 업체가 Cisco 장비와 해당 PID·속도를 공식 지원하는지, 자체 보증과 교환 정책이 있는지 확인해야 합니다.
